`--signup ...` and `--social ...` (see `site-src/README.md`).

## Publishing (automatic)

**This repo is generated. Don't edit it by hand:** every publish replaces it.

The source is `store/site-src/` in the private repo `XaviHeras/zoolens-app`. To change the site:
1. Edit `store/site-src/` (copy: `content-en.mjs`, `content-es.mjs`; privacy and 404: `pages-extra.mjs`), always in both languages.
2. Run `bash store/site-src/build-public.sh`. It rebuilds `store/site/` with the public settings in `public-build.args` and runs the pre-publish guards.
3. Commit the source and the rebuilt `store/site/` on a branch, then open a pull request. The "Website" GitHub Action checks it.
4. The owner merges. The same Action then copies `store/site/` into `XaviHeras/zoolens`, and GitHub Pages updates the live site in a minute or two. **Merging is publishing.**

The Action needs the secret `ZOOLENS_SITE_TOKEN` in `zoolens-app`: a fine-grained token for `XaviHeras/zoolens` only, with Contents: Read and write.

## Before launch

- When the app has an App Store ID, replace the "Coming soon to the App Store" lines with the badge and link, and add the `MobileApplication` structured data.
- Sign-up and social links: change `public-build.args` (see `store/site-src/README.md`), then rebuild.
